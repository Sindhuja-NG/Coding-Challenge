# Coding-Challenge
Employee Dataset Analysis Coding Challenge

The Employee Dataset consists of 151 rows and 9 columns containing employee-related information such as Employee ID, Name, Department, Country, Gender, Salary, Date of Joining, and Performance Rating. The objective of this project was to clean, analyze, and visualize the dataset using Microsoft Excel tools and techniques.
The project focused on data cleaning, formula implementation, PivotTable creation, dashboard designing, and visualization to derive meaningful insights from the employee data.
